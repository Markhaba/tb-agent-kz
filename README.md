# Өкпе кескіндерін талдауға арналған ЖИ агенті

## Іске қосу (macOS / Linux)
```bash
cd tb_agent_kz
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
Браузер: http://localhost:8501

Бұл зерттеу прототипі. PNG/JPG форматындағы жеке рентген кескінін талдайды. Толық КТ/DICOM сериясын талдамайды. КТ кескінін талдау модельдің осы модальдылықта үйретілгені мен тексерілгені расталғанға дейін бұғатталған.

**Маңызды:** Модель сыныптарының нақты атауларын тексеріңіз. Тек `tb`, `tuberculosis`, `tuberkulez`, `туберкулез`, `туберкулёз` атаулары оң анықтама ретінде есептеледі. Басқа атаулар қолданылса, оларды нақты белгіленген сынып семантикасына сәйкес кодта реттеу керек. Сенімділік көрсеткіші медициналық диагноз емес.
